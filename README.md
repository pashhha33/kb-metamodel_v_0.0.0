# Метамодель личной базы знаний + плагин Obsidian

Репозиторий является единственным источником истины и единственным каналом
коммуникации между ИИ-чатом, ИИ-агентом и пользователем.

## Роли
- **Пользователь** — заносит артефакты вручную, коммитит и пушит.
- **ИИ-чат** — проектирует и ревьюит; только читает репозиторий. См. `CHAT.md`.
- **ИИ-агент** — реализует артефакты в изолированном пространстве; не коммитит.
  См. `AGENTS.md`.

## Структура
```
.
├── STATE.md          # текущая фаза/итерация/следующий шаг
├── CHAT.md           # инструкции чата (статические)
├── AGENTS.md         # инструкции агента (статические)
├── REFERENCE.md      # указатель на референсную метамодель (опционально)
├── metamodel/        # артефакты метамодели
├── plugin/           # артефакты плагина
├── tasks/            # спецификации задач для агента (task-NNN.md)
├── reviews/          # ревью от чата (review-NNN.md)
└── agent-output/     # результаты агента (agent-output-NNN.md)
```

## Быстрый старт
1. Прочитать `STATE.md`.
2. Чат: `/read-repo` → `/design` → `/specify`.
3. Пользователь сохраняет `task-NNN.md` в `tasks/` и коммитит.
4. Агент: `/read-repo` → `/implement`.
5. Пользователь переносит результат в `agent-output/` и коммитит.
6. Чат: `/review`. Пользователь сохраняет `review-NNN.md` в `reviews/`.
7. Чат: `/fixate`. Пользователь обновляет `STATE.md` и коммитит.
8. Повторять по фазам и итерациям.
